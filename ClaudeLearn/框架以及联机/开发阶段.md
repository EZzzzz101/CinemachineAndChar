## 🔄 Phase 2 — 玩家 HUD（当前在做）

### 目标
- [ ] `PlayerController` 加血量属性 + 事件发射
- [ ] `UI/View/HUD/PlayerHPBarView.cs` — 血条显示
- [ ] `UI/Controller/PlayerHUDController.cs` — 监听事件，刷新血条

### 数据流
```
PlayerController.HP 变化
  → EventBus.Emit("player.hp.changed", ratio)
  → PlayerHUDController.OnHPChanged()
  → PlayerHPBarView.SetHP(ratio)
```
